# Last Mile Delivery Intelligence Dashboard

## Project Overview

This project focuses on analyzing food delivery operations using Power BI, SQL, and Python to uncover operational inefficiencies, delivery trends, and risk exposure patterns.

The dashboard simulates real-world logistics intelligence used in delivery platforms like Swiggy and Zomato to monitor:
- delivery efficiency
- order distribution
- distance-based performance
- risk exposure
- peak vs non-peak operations

The objective of this project is to transform raw operational delivery data into actionable business insights through data analytics and visualization.

# Business Insights Generated

- Peak-hour operations showed higher delivery risk exposure.
- Medium-distance deliveries contributed the largest order volume.
- Delivery performance varied significantly across time slots.
- Non-peak periods showed improved operational efficiency.
